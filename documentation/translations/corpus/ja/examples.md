Pairs of English and the Japanese it should become. They are here for the tone: short sentences, the polite form without stiffness, no word for "you", and the words Home Assistant itself uses.

| English                                                                                           | Japanese                                                                                                |
| ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Spook reported a problem, and you want it gone.                                                   | Spookが問題を報告したので、解消したいという場合です。                                                   |
| You don't have to mark anything as done.                                                          | 何かを完了済みにする必要はありません。                                                                  |
| Nothing there? Then your setup is clean, or Spook is still looking.                               | 何もありませんか？それなら設定に問題がないか、Spookがまだ探しているところです。                         |
| An automation that stopped working usually does so without a word. Spook tells you.               | 動かなくなったオートメーションは、たいてい何も言いません。Spookが教えてくれます。                       |
| That is a bit late.                                                                               | それでは少し遅すぎます。                                                                                |
| It happens, and it is a bug.                                                                      | 起こることはあります。そしてそれはバグです。                                                            |
| A bug report without logs is a guessing game.                                                     | ログのないバグ報告は、当て推量にしかなりません。                                                        |
| A repair that cries wolf is a bug.                                                                | オオカミ少年のような修復はバグです。                                                                    |
| The repair disappears by itself once it is fixed.                                                 | 直せば、修復は自然に消えます。                                                                          |
| When that area does not exist, it raises a repair that names the automation and the missing area. | そのエリアが存在しない場合、Spookはオートメーションと見つからないエリアの名前を書いた修復を作成します。 |
| Select **Save**.                                                                                  | **保存**を選択します。                                                                                  |
| Go to **Settings** > **Devices & services**.                                                      | **設定** > **デバイスとサービス**に移動します。                                                         |
| No files to copy, no YAML.                                                                        | コピーするファイルも、YAMLもありません。                                                                |
| Like the guest mode you switch on in December and find again in March.                            | 12月にオンにして、3月になって思い出すゲストモードのように。                                             |
| An alarm nobody hears is just furniture.                                                          | 誰にも聞こえない警報は、ただの家具です。                                                                |
| Spook doesn't mind.                                                                               | Spookは気にしません。                                                                                   |

What these show:

- No space between Japanese and Latin: "Spookが教えてくれます", "YAMLもありません". No space around a bold label.
- The reader is never named. "You want it gone" becomes what is wanted, not who wants it.
- "Cries wolf" has a Japanese equivalent, "オオカミ少年", so it stays an idiom. Where Japanese has none, write the meaning plainly.
- "Raises a repair" is "修復を作成します". An automation is "有効" or "無効", the words the interface shows.
- Steps end in "〜します", the polite form, not "〜しろ" and not "〜していただけます".
- Full-width "？" and "、", half-width digits.
