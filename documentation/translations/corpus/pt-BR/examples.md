Pairs of English and the Brazilian Portuguese it should become. They are here for the tone: short sentences, "você", and the words Home Assistant itself uses.

| English                                                                                           | Brazilian Portuguese                                                                     |
| ------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Spook reported a problem, and you want it gone.                                                   | O Spook relatou um problema, e você quer se livrar dele.                                 |
| You don't have to mark anything as done.                                                          | Você não precisa marcar nada como resolvido.                                             |
| Nothing there? Then your setup is clean, or Spook is still looking.                               | Não tem nada? Então sua instalação está limpa, ou o Spook ainda está procurando.         |
| An automation that stopped working usually does so without a word. Spook tells you.               | Uma automação que parou de funcionar costuma fazer isso sem dizer nada. O Spook avisa.   |
| That is a bit late.                                                                               | Isso é um pouco tarde.                                                                   |
| It happens, and it is a bug.                                                                      | Acontece, e é um bug.                                                                    |
| A bug report without logs is a guessing game.                                                     | Um relato de bug sem logs é um jogo de adivinhação.                                      |
| A repair that cries wolf is a bug.                                                                | Um reparo que dá alarme falso é um bug.                                                  |
| The repair disappears by itself once it is fixed.                                                 | O reparo some sozinho assim que o problema for resolvido.                                |
| When that area does not exist, it raises a repair that names the automation and the missing area. | Se essa área não existe, o Spook cria um reparo que cita a automação e a área que falta. |
| Select **Save**.                                                                                  | Selecione **Salvar**.                                                                    |
| Go to **Settings** > **Devices & services**.                                                      | Vá em **Configurações** > **Dispositivos e serviços**.                                   |
| No files to copy, no YAML.                                                                        | Nenhum arquivo para copiar, nada de YAML.                                                |
| Like the guest mode you switch on in December and find again in March.                            | Como o modo convidado que você liga em dezembro e reencontra em março.                   |
| An alarm nobody hears is just furniture.                                                          | Um alarme que ninguém ouve é só um móvel.                                                |
| Spook doesn't mind.                                                                               | O Spook não se importa.                                                                  |

What these show:

- "O Spook", with the article, every time. "Do Spook", "pelo Spook".
- "Você" where it is needed, not in every sentence: "sua instalação", not "a sua instalação de você".
- "Raises a repair" is "cria um reparo". A trigger "é acionado". An automation is "ativada" or "desativada".
- "Setup" is "instalação", "issue" is "problema", "the logs" are "os logs", because that is what Home Assistant calls them in Brazil.
- Brazilian, not European: "você", "arquivo", "tela", never "ficheiro" or "ecrã".
