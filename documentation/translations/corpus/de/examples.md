Pairs of English and the German it should become. They are here for the tone: short main clauses, "du", and the words Home Assistant itself uses.

| English                                                                                           | German                                                                                                       |
| ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Spook reported a problem, and you want it gone.                                                   | Spook hat ein Problem gemeldet, und du willst es loswerden.                                                  |
| You don't have to mark anything as done.                                                          | Du musst nichts als erledigt markieren.                                                                      |
| Nothing there? Then your setup is clean, or Spook is still looking.                               | Nichts da? Dann ist bei dir alles sauber, oder Spook sucht noch.                                             |
| An automation that stopped working usually does so without a word. Spook tells you.               | Eine Automation, die nicht mehr funktioniert, sagt das meistens nicht dazu. Spook schon.                     |
| That is a bit late.                                                                               | Das ist etwas spät.                                                                                          |
| It happens, and it is a bug.                                                                      | Das kommt vor, und es ist ein Bug.                                                                           |
| A bug report without logs is a guessing game.                                                     | Eine Fehlermeldung ohne Protokolle ist ein Ratespiel.                                                        |
| A repair that cries wolf is a bug.                                                                | Eine Reparatur, die falschen Alarm schlägt, ist ein Bug.                                                     |
| The repair disappears by itself once it is fixed.                                                 | Die Reparatur verschwindet von selbst, sobald es behoben ist.                                                |
| When that area does not exist, it raises a repair that names the automation and the missing area. | Gibt es diesen Bereich nicht, legt es eine Reparatur an, die die Automation und den fehlenden Bereich nennt. |
| Select **Save**.                                                                                  | Wähle **Speichern** aus.                                                                                     |
| Go to **Settings** > **Devices & services**.                                                      | Gehe zu **Einstellungen** > **Geräte & Dienste**.                                                            |
| No files to copy, no YAML.                                                                        | Keine Dateien kopieren, kein YAML.                                                                           |
| Like the guest mode you switch on in December and find again in March.                            | Wie der Gästemodus, den du im Dezember einschaltest und im März wiederfindest.                               |
| An alarm nobody hears is just furniture.                                                          | Ein Alarm, den niemand hört, ist nur ein Möbelstück.                                                         |
| Spook doesn't mind.                                                                               | Spook stört das nicht.                                                                                       |

What these show:

- "It does not exist any more" is "gibt es nicht mehr", not "existiert nicht mehr". Plain verbs.
- Spook is "es", and never gets an article.
- "Raises a repair" is "legt eine Reparatur an". A trigger "löst aus". An automation is "ausgeschaltet" or "eingeschaltet". A step that is switched off inside an automation is "deaktiviert".
- "Setup" is "Installation", "issue" is "Problem", "the logs" are "die Protokolle", because that is what Home Assistant calls them in German.
- "Home Assistant" is never part of a hyphenated compound: "die Version von Home Assistant".
