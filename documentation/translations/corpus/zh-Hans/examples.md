Pairs of English and the Simplified Chinese it should become. They are here for the tone: short sentences, "你", full-width punctuation, and the words Home Assistant itself uses.

| English                                                                                           | Simplified Chinese                                                         |
| ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Spook reported a problem, and you want it gone.                                                   | Spook 报告了一个问题，你想让它消失。                                       |
| You don't have to mark anything as done.                                                          | 你不需要把任何东西标记为已完成。                                           |
| Nothing there? Then your setup is clean, or Spook is still looking.                               | 什么都没有？那就是你的系统很干净，或者 Spook 还在找。                      |
| An automation that stopped working usually does so without a word. Spook tells you.               | 停止工作的自动化通常一声不吭。Spook 会告诉你。                             |
| That is a bit late.                                                                               | 这有点晚了。                                                               |
| It happens, and it is a bug.                                                                      | 这种情况会发生，而且这是个 bug。                                           |
| A bug report without logs is a guessing game.                                                     | 没有日志的 bug 报告，只能靠猜。                                            |
| A repair that cries wolf is a bug.                                                                | 喊“狼来了”的修复就是 bug。                                                 |
| The repair disappears by itself once it is fixed.                                                 | 问题解决后，修复会自己消失。                                               |
| When that area does not exist, it raises a repair that names the automation and the missing area. | 如果该区域不存在，Spook 会创建一条修复，写明是哪个自动化，缺的是哪个区域。 |
| Select **Save**.                                                                                  | 选择**保存**。                                                             |
| Go to **Settings** > **Devices & services**.                                                      | 前往**设置** > **设备与服务**。                                            |
| No files to copy, no YAML.                                                                        | 不用复制文件，也不用写 YAML。                                              |
| Like the guest mode you switch on in December and find again in March.                            | 就像你十二月打开、到三月才又想起来的访客模式。                             |
| An alarm nobody hears is just furniture.                                                          | 没人听得到的警报，只是件家具。                                             |
| Spook doesn't mind.                                                                               | Spook 不介意。                                                             |

What these show:

- A space between Chinese and Latin: "Spook 会告诉你", "写 YAML". None between Chinese and full-width punctuation.
- "Cries wolf" has a Chinese equivalent, "喊“狼来了”", so it stays an idiom. Where Chinese has none, write the meaning plainly.
- "Raises a repair" is "创建一条修复". A trigger "触发". An automation is "已启用" or "已禁用".
- "Setup" is "系统" or "安装", "issue" is "问题", "the logs" are "日志", because that is what Home Assistant calls them in Chinese.
- A list of two in one sentence uses the enumeration comma "、", not ",".
