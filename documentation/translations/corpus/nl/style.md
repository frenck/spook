Dutch, as spoken in the Netherlands, the way one Home Assistant user explains something to another.

## Address

- Informal, always: "je", "jij", "jouw". Never "u" or "uw". Home Assistant's own Dutch interface says "je" too, so the docs and the product sound like one thing.
- Instructions in the imperative, without "je": "Ga naar **Instellingen**", "Selecteer **Opslaan**".
- "We" stays "we". Frenck speaks as "ik" where the English has "I" or "my".

## Tone

- Dutch directness is the point. Shorter is better. Where English softens ("you might want to"), Dutch says it ("doe dit").
- No stiff written Dutch: "echter", "tevens", "indien", "middels", "betreft", "dient te". Write "maar", "ook", "als", "met", "moet".
- No diminutives to be cute, no exclamation marks the English does not have.
- Dry humor stays dry. "That is a bit late." is "Dat is wat laat.", not a joke with a wink.

## Words

- "Select" is "selecteer" or "kies". Never "klik".
- Use the words Home Assistant uses in Dutch: automatisering, entiteit, apparaat, ruimte, verdieping, voorwaarde, actie, integratie. The glossary has the list.
- English words Dutch Home Assistant users use stay English: trigger, helper, dashboard, blueprint, template, script, label, snoozen.
- A compound is one word, or gets a hyphen when it has an English or abbreviated part: "automatiseringseditor", "entiteit-ID", "debug-logging", "YAML-configuratie".
- "Spook" is a gift here: it already means ghost. The name stays "Spook", capitalized, without an article. Do not explain the pun, and do not write "het spook" for the product.

## Typography

- Quotes: "dubbele" straight quotes, like the English.
- A sentence after a colon starts lowercase, unless it is a name.
- Numbers and versions as in the English. Times in `code` are not touched.
