Pairs of English and the Italian it should become. They are here for the tone: short sentences, "tu", and the words Home Assistant itself uses.

| English                                                                                           | Italian                                                                                          |
| ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Spook reported a problem, and you want it gone.                                                   | Spook ha segnalato un problema, e vuoi liberartene.                                              |
| You don't have to mark anything as done.                                                          | Non devi segnare niente come fatto.                                                              |
| Nothing there? Then your setup is clean, or Spook is still looking.                               | Non c'è niente? Allora la tua installazione è pulita, oppure Spook sta ancora cercando.          |
| An automation that stopped working usually does so without a word. Spook tells you.               | Un'automazione che smette di funzionare di solito non dice niente. Spook sì.                     |
| That is a bit late.                                                                               | È un po' tardi.                                                                                  |
| It happens, and it is a bug.                                                                      | Succede, ed è un bug.                                                                            |
| A bug report without logs is a guessing game.                                                     | Una segnalazione di bug senza registri è un gioco a indovinare.                                  |
| A repair that cries wolf is a bug.                                                                | Una riparazione che grida al lupo è un bug.                                                      |
| The repair disappears by itself once it is fixed.                                                 | La riparazione sparisce da sola appena il problema è risolto.                                    |
| When that area does not exist, it raises a repair that names the automation and the missing area. | Se quell'area non esiste, Spook crea una riparazione che nomina l'automazione e l'area mancante. |
| Select **Save**.                                                                                  | Seleziona **Salva**.                                                                             |
| Go to **Settings** > **Devices & services**.                                                      | Vai in **Impostazioni** > **Dispositivi e servizi**.                                             |
| No files to copy, no YAML.                                                                        | Niente file da copiare, niente YAML.                                                             |
| Like the guest mode you switch on in December and find again in March.                            | Come la modalità ospite che accendi a dicembre e ritrovi a marzo.                                |
| An alarm nobody hears is just furniture.                                                          | Un allarme che nessuno sente è solo un soprammobile.                                             |
| Spook doesn't mind.                                                                               | A Spook non importa.                                                                             |

What these show:

- The subject pronoun goes: "vuoi", "devi", not "tu vuoi".
- Spook takes no article. "Spook sì." is the whole answer to "Spook tells you."
- "Raises a repair" is "crea una riparazione". A trigger "si attiva". An automation is "attivata" or "disattivata".
- "Setup" is "installazione", "issue" is "problema", "the logs" are "i registri", because that is what Home Assistant calls them in Italian.
- "È" with its accent, never "E'".
