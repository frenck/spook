The input number :term[helper] in :term[Home Assistant] holds a number you can change from a dashboard, as a slider or a box to type in, and use in the conditions and triggers of an :term[automation].

Spook adds actions to the input number :term[integration] to create and delete these helpers on the fly, jump one to its minimum or maximum, and change its range. It also teaches the existing increase and decrease actions to step by any amount, and to go round from one end to the other.

## Actions

Spook adds five actions for input numbers, and extends two that Home Assistant already has. You find them wherever you add an action, marked with a 👻.

### Create an input number

Creates a new input number helper, the same as adding one on the helpers page.

Some numbers only matter for a while: a countdown for a game night, a temperature for this week's guest room, the volume of a party playlist. Made by hand, that helper stays on the helpers page long after. Made with this action, the script makes it when it needs it, and [deletes it](#delete-an-input-number) when it is done. A blueprint can do the same, so whoever uses it does not have to make the helper first.

**How to use it**

1. Open the automation or script that should make the helper, and select **Add action**.
2. Search for **create an input number**, and select **Input number: Create an input number 👻**.
3. Fill in **Name**, like `My counter`.
4. Optionally, set **Input number entity ID** to pick the entity ID yourself, and any of **Minimum**, **Maximum**, **Initial value**, **Step size**, **Display mode**, **Icon** and **Unit of measurement**.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=input_number.create) opens it in your Home Assistant, ready to run once.

A counter from 0 to 100, shown as a slider:

```yaml
action: input_number.create
data:
  name: "My counter"
  input_number_id: my_counter
  min: 0
  max: 100
  step: 1
  mode: slider
```

### Delete an input number

Deletes one or more input number helpers.

The other half of [Create an input number](#create-an-input-number): the script that made a helper cleans it up again. It works on any input number made in the UI as well, disabled ones included.

**How to use it**

1. Open the automation or script that should do the cleaning up, and select **Add action**.
2. Search for **delete an input number**, and select **Input number: Delete an input number 👻**.
3. Under **Entity ID**, choose the input numbers to delete.
4. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=input_number.delete) opens it in your Home Assistant, ready to run once. Mind that it really deletes.

### Decrease value

Lowers the value of an input number, by its own step or by any amount you give.

Home Assistant already has this action, but it only ever moves one step. Going down by five means calling it five times, or writing a template. Spook adds an **Amount**, so one call does it. It also adds **Cycle**: go past the bottom, and it carries on from the top, like a dial that goes round.

**How to use it**

1. Open the automation or script that should lower the value, and select **Add action**.
2. Search for **decrease value**, and select **Input number: Decrease value 👻**.
3. Under **Targets**, choose the input number.
4. Optionally, set **Amount**, like `5`, and turn on **Cycle** to go round instead of stopping at the minimum.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=input_number.decrement) opens it in your Home Assistant, ready to run once.

| :term[Action response]                            | No response                                                                                                                                                                                                                                                                                                                                                                     |

| **Action data parameters** |                |              |                                   |
| -------------------------- | -------------- | ------------ | --------------------------------- |
| **Attribute**              | **Type**       | **Required** | **Default / Example**             |
| `amount`                   | :term[float]   | No           | Defaults to configured step value |
| `cycle`                    | :term[boolean] | No           | `false`                           |

Home Assistant already has this action. Spook adds the `amount` and `cycle` attributes to it. Without an `amount`, the action uses the step of the input number. The `amount` has to be a multiple of that step. With `cycle`, going past the end of the range carries on from the other end, the same way selecting the next option cycles a select.

:::

:::accordion-item{label="Example actions in YAML" icon="i-mdi-code-braces"}

Five down in one go:

```yaml
action: input_number.decrement
target:
  entity_id: input_number.my_input_number
data:
  amount: 5
```

:::
:::accordion-item{label="Known limitations" icon="i-mdi-alert-outline"}

- An amount that is not a multiple of the step of the input number is refused, with an error saying so.
- Without **Cycle**, the value stops at the minimum.

:::

### Set range

Changes the minimum, maximum or step of an input number, the same as editing it in the UI.

A slider for the position in a song needs a maximum as long as the song. A target for the oven needs a different range for baking than for a pizza. Without this action, the range is whatever you set by hand, and the automation has to live with it. With it, the automation sets the range to fit what is going on.

**How to use it**

1. Open the automation or script that should change the range, and select **Add action**.
2. Search for **set range**, and select **Input number: Set range 👻**.
3. Under **Targets**, choose the input number.
4. Set any of **Minimum**, **Maximum** and **Step**. What you leave out stays as it is.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=input_number.set_range) opens it in your Home Assistant, ready to run once.

:::


- Only input numbers made in the UI can be changed. One set up in YAML is refused.
- This takes an admin when a user calls it, since it changes how the helper is set up. Automations and scripts are not affected.

## Use cases

What people use this for:

- Create input number helpers from a blueprint or script, so whoever uses it does not have to set them up first.
- Clean up the temporary input number helpers an automation or script made, once they are no longer needed.
- Set an input number to its maximum or minimum with a single action.
- Increase or decrease by an amount in one go, instead of calling `input_number.decrement` or `input_number.increment` several times.
