The cover :term[integration] is how :term[Home Assistant] controls blinds, shutters, curtains, awnings and garage doors.

Home Assistant can move a cover to a position, but not a bit further. Spook adds the step.

## Actions

Spook adds two actions for covers. You find them wherever you add an action, marked with a 👻.

### Increase position

Moves a cover a step further open, stopping at fully open.

A button that opens the blinds a bit more each time you press it, or an automation that lets in a little more light as the sun goes down. Without this, that is a template that reads the position, adds to it, and makes sure it does not go past 100. This action does all of that.

**How to use it**

1. Open the automation or script that should do this, and select **Add action**.
2. Search for **increase position**, and select **Cover: Increase position 👻**.
3. Under **Targets**, choose the covers.
4. Leave **Step** empty to move ten percent, or fill in how many percent, like `20`.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=cover.increase_position) opens it in your Home Assistant, ready to run once.

| **Action data parameters** |                |              |                       |
| -------------------------- | -------------- | ------------ | --------------------- |
| **Attribute**              | **Type**       | **Required** | **Default / Example** |
| `step`                     | :term[integer] | No           | `10`                  |

Both actions, increase and decrease, work the same way:

- Positions are whole percentages, from 0 for fully closed to 100 for fully open, the same as Home Assistant's own.
- The step is the one you give, or ten percent. A cover does not say how far one step is, the way a thermostat does.
- A step that would go past fully open or fully closed stops there.

:::

:::accordion-item{label="Example actions in YAML" icon="i-mdi-code-braces"}

Open the living room blinds another twenty percent:

```yaml
action: cover.increase_position
target:
  entity_id: cover.living_room_blinds
data:
  step: 20
```

:::

:::accordion-item{label="Known limitations" icon="i-mdi-alert-outline"}

- A cover that can only open and close, like most garage doors, cannot be targeted. There is no position to step.
- A cover that has not reported a position yet is left alone.
- The tilt of the slats is not stepped. That is a different setting, with actions of its own in Home Assistant.

:::
::

### Decrease position

Moves a cover a step further closed, stopping at fully closed.

The other way round from [Increase position](#increase-position): close the blinds a bit when the sun hits the screen, or the curtains a little further each time you press a button. Same rules, the other direction.

**How to use it**

1. Open the automation or script that should do this, and select **Add action**.
2. Search for **decrease position**, and select **Cover: Decrease position 👻**.
3. Under **Targets**, choose the covers.
4. Leave **Step** empty to move ten percent, or fill in how many percent, like `20`.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=cover.decrease_position) opens it in your Home Assistant, ready to run once.
