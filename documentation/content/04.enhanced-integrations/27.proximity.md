The proximity integration in Home Assistant tracks how close devices or persons are to a zone. Use it to trigger automations when somebody gets near a location, or leaves it.

## Repairs

Spook looks through your proximity configurations for zones, persons and device trackers that no longer exist, and tells you in the :term[repairs dashboard]{to="repairs"}. Each repair names the proximity configuration and what is missing from it.

Fixing one usually goes the same way: go to **Settings** > **Devices & services**, open **Proximity**, select **Configure** on the configuration the repair names, and change what the repair points at. Spook looks again when you save, and takes the repair away by itself. New to repairs? Follow [Fix your first repair](/fix-your-first-repair).

### Unknown zone

A proximity configuration measures the distance to a zone that no longer exists, usually because the zone was removed or renamed. With the zone gone, there is nothing left to measure the distance to.

**How to fix it:** Home Assistant does not let you change the zone of a proximity configuration. So either bring the zone back, with the same entity ID, or delete this proximity configuration and add a new one for the right zone. The repair disappears by itself once it is fixed.

::accordion
:::accordion-item{label="How Spook checks this" icon="i-mdi-magnify"}

Spook looks at the zone of every proximity configuration. When that zone is gone, it raises a repair that names the proximity configuration and the missing zone.

Spook looks again whenever an integration loads, the entity registry changes, or a proximity configuration is changed.

:::
::

### Unknown tracked devices or persons

A proximity configuration tracks a person or device tracker that no longer exists, usually because it was renamed or removed. That person or device is no longer part of the distances it reports.

**How to fix it:** Open the proximity configuration the repair names, select **Configure**, and remove the missing person or device tracker. Add the one that replaced it, if there is one. The repair disappears by itself once it is fixed.

::accordion
:::accordion-item{label="How Spook checks this" icon="i-mdi-magnify"}

Spook looks at the devices and persons every proximity configuration tracks. When one of them is gone, it raises a repair that names the proximity configuration and the missing device or person.

Spook looks again whenever an integration loads, the entity registry changes, or a proximity configuration is changed.

:::
::

### Unknown ignored zones

A proximity configuration ignores a zone that no longer exists. Not critical: ignoring something that is not there does nothing. Still a good one to clean up.

**How to fix it:** Open the proximity configuration the repair names, select **Configure**, and remove the missing zone from the zones to ignore. The repair disappears by itself once it is fixed.

::accordion
:::accordion-item{label="How Spook checks this" icon="i-mdi-magnify"}

A proximity configuration can ignore certain zones. Spook looks at those for every proximity configuration. When an ignored zone is gone, it raises a repair that names the proximity configuration and the missing zone.

Spook looks again whenever an integration loads, the entity registry changes, or a proximity configuration is changed.

:::
::
