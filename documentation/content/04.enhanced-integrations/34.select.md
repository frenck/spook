A select :term[entity] is a dropdown that comes with a device or an integration: the effect of a light strip, the mode of a robot vacuum, the sound profile of a speaker. Unlike the [input select](/input-select) helper, you do not make it yourself: an integration does.

Spook adds one action to it: pick an option at random.

## Actions

Spook adds one action for select entities. You find it wherever you add an action, marked with a 👻.

### Select random option

Picks a random option of a select entity, from all of its options or from the ones you name.

The same light effect every evening gets old. Picking one at random takes a template that reads the options, shuffles them and hands one back. This action does that for you. Name a few options to keep it to the ones you like: a random effect for the living room lights, but never the strobe.

**How to use it**

1. Open the automation or script that should do this, and select **Add action**.
2. Search for **random**, and select **Select: Select random option 👻**.
3. Under **Targets**, pick the select entities.
4. Optionally, fill in **Options** to pick only from those. Leave it empty to pick from all of them.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=select.random) opens it in your Home Assistant, ready to run once.

| `options`                  | :term[list of strings]{to="list"} | No           | Defaults to all available options |

The `options` attribute is a :term[list of strings]{to="list"}: the options to pick a random one from. Leave it out, and all options the select entity offers are used.

:::

:::accordion-item{label="Example actions in YAML" icon="i-mdi-code-braces"}

Any effect the light strip has:

```yaml
action: select.random
target:
  entity_id: select.effect
```

One of three colors, nothing else:

```yaml
action: select.random
target:
  entity_id: select.color
data:
  options:
    - red
    - green
    - blue
```

:::

:::accordion-item{label="Known limitations" icon="i-mdi-alert-outline"}

- The option it picks can be the one already selected.
- An option you name that the select entity does not have is an error, when it is the one picked.

:::
::

## Use cases

What people use this for:

- Pick a random preset or playlist from a list of options, for a bit of surprise in your automations.
