A zone in :term[Home Assistant] is a circle on the map: home, work, the school, the gym. Home Assistant uses zones to tell where people and devices are, and :term[automations]{to="automation"} can act when somebody enters or leaves one.

Home Assistant lets you draw zones by hand, in the settings. Spook adds actions for it, so an automation or a script can make a zone, move or resize it, and delete it again.

## Actions

Spook adds three actions for zones. You find them wherever you add an action, marked with a 👻.

### Create a zone

Adds a new zone, the same as drawing one in the settings.

A zone does not have to be a place you go to every week. Make one around the spot you just parked, and get a reminder when you walk back to it. Or around a friend's house for the evening, and delete it again tomorrow. Make it passive, and it is only there for your automations: not on the map, and it does not change where anybody is.

**How to use it**

1. Open the automation or script that should make the zone, and select **Add action**.
2. Search for **create a zone**, and select **Zone: Create a zone 👻**.
3. Fill in the **Name**, the **Latitude** and the **Longitude**.
4. Optionally, set the **Radius** in meters, the **Icon**, and turn on **Passive**. A passive zone only works for automations: nobody is shown as being in it.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=zone.create) opens it in your Home Assistant, ready to run once.

### Update a zone

Changes an existing zone: its name, icon, place, size, or whether it is passive.

Zones do not always stay put. Move the "car" zone to where the car is now. Make the home zone bigger in winter, when the drive home takes longer and the heating needs a head start. Only what you fill in changes; everything else stays as it is.

**How to use it**

1. Open the automation or script that should change the zone, and select **Add action**.
2. Search for **update a zone**, and select **Zone: Update a zone 👻**.
3. Under **Entity ID**, pick the zone.
4. Fill in only what should change, like the **Latitude** and **Longitude** to move it, or the **Radius** to resize it.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=zone.update) opens it in your Home Assistant, ready to run once.

| **Action data parameters** |                |              |                          |
| -------------------------- | -------------- | ------------ | ------------------------ |
| **Attribute**              | **Type**       | **Required** | **Default / Example**    |
| `entity_id`                | :term[string]  | Yes          | `zone.statue_of_liberty` |
| `name`                     | :term[string]  | No           | `Statue of Liberty`      |
| `icon`                     | :term[string]  | No           | `mdi:map-marker`         |
| `latitude`                 | :term[float]   | No           | `40.6892494`             |
| `longitude`                | :term[float]   | No           | -74.0445004              |
| `radius`                   | :term[float]   | No           | 100                      |
| `passive`                  | :term[boolean] | No           | `true`                   |

The `radius` is in meters. Only the parameters you give are updated. The rest stays as it is. Set `passive` to make a zone only there for automations, or to make a passive zone an ordinary one again.

The home zone (`zone.home`) can be moved and resized too, with `latitude`, `longitude` and `radius`. It is drawn from the location of your whole Home Assistant instance, so that is what changes: the same location Home Assistant's own `homeassistant.set_location` sets, and the one everything else that uses your location follows. Its name and icon cannot be changed this way, its radius is in whole meters, and it is never passive.

:::

:::accordion-item{label="Example actions in YAML" icon="i-mdi-code-braces"}

A new name, and a bigger circle:

```yaml
action: zone.update
data:
  entity_id: zone.statue_of_liberty
  name: "Statue of Liberty, New York"
  radius: 250
```

Resizing the home zone:

```yaml
action: zone.update
data:
  entity_id: zone.home
  radius: 250
```

:::

:::accordion-item{label="Known limitations" icon="i-mdi-alert-outline"}

- Zones set up in YAML cannot be updated. Change those in the YAML.
- Moving the home zone moves the location of your whole Home Assistant instance, and everything that follows it, like the sun.

:::
::

### Delete a zone

Deletes one or more zones.

The other half of [Create a zone](#create-a-zone). A zone an automation made for the evening is gone again the next morning, and your map stays clean.

**How to use it**

1. Open the automation or script that should do the deleting, and select **Add action**.
2. Search for **delete a zone**, and select **Zone: Delete a zone 👻**.
3. Under **Entity ID**, pick the zones to delete.
4. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=zone.delete) opens it in your Home Assistant, ready to run once. Mind that it really deletes.

Delete one zone:

```yaml

```

```yaml
action: zone.delete

  entity_id:

```

- Only zones made in the UI, or with [Create a zone](#create-a-zone), can be deleted. Zones set up in YAML cannot.

## Use cases

What people use this for:

- Create and update zones around a car or a person from an automation. That way you can tell who is close to the car, or get notified when you are near a certain person.
