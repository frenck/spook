The number :term[integration] provides numeric inputs to control :term[devices & services]{to="device"}. Unlike the [input number](/input-number) helper, you do not create these yourself. Other integrations provide them, like the volume of a speaker or the delay of a motion sensor.

Spook adds actions to the number :term[integration] to set a number to its minimum or maximum, and to increase or decrease it by a given amount.

## Actions

Spook adds four actions for numbers. You find them wherever you add an action, marked with a 👻.

### Decrease value

Lowers the value of a number, by its own step or by any amount you give.

Home Assistant can set a number, but not lower it. "A bit less" means a template that reads the value, subtracts from it, and keeps it above the minimum. This action does all of that.

**How to use it**

1. Open the automation or script that should lower the value, and select **Add action**.
2. Search for **decrease value**, and select **Number: Decrease value 👻**.
3. Under **Targets**, choose the number.
4. Optionally, set **Amount**, like `5`. Leave it empty to go down by the number's own step.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=number.decrement) opens it in your Home Assistant, ready to run once.

:::

:::accordion-item{label="Example actions in YAML" icon="i-mdi-code-braces"}

Five down in one go:

```yaml
action: number.decrement
target:
  entity_id: number.my_number
data:
  amount: 5
```

:::
:::accordion-item{label="Known limitations" icon="i-mdi-alert-outline"}

- An amount that is not a multiple of the step of the number is refused, with an error saying so.

:::

The same as [Decrease value](#decrease-value), the other way up. One call goes up by as much as you want, and stops at the maximum of the number.

1. Open the automation or script that should raise the value, and select **Add action**.

3. Under **Targets**, choose the number.
4. Optionally, set **Amount**, like `5`. Leave it empty to go up by the number's own step.
5. Select **Save**.

## Use cases

What people use this for:

- Set a number entity to its maximum or minimum with a single action.
- Increase or decrease a number entity with a single action, instead of calling `number.set_value` with a template that does the math on the current state.
