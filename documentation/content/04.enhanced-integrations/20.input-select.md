The input select :term[helper] in :term[Home Assistant] holds a list of options to choose from, shown as a dropdown or a row of buttons, and usable in the conditions and triggers of an :term[automation].

Spook adds actions to the input select :term[integration] to create and delete these helpers, pick a random option, and shuffle, sort or reverse the list of options.

## Actions

Spook adds six actions for input selects. You find them wherever you add an action, marked with a 👻.

### Create an input select

Creates a new input select (dropdown) helper, the same as adding one on the helpers page.

Some choices only matter for a while. Tonight's movie genre, who brings what to the barbecue, the playlist for a party. Made by hand, that helper stays on the helpers page long after. Made with this action, the script makes it when it needs it, and [deletes it](#delete-an-input-select) when it is done.

**How to use it**

1. Open the automation or script that should make the helper, and select **Add action**.
2. Search for **create an input select**, and select **Input select: Create an input select 👻**.
3. Fill in **Name**, like `Movie night`, and the **Options** to choose from.
4. Optionally, set **Input select entity ID** to pick the entity ID yourself, **Initial option**, and **Icon**.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=input_select.create) opens it in your Home Assistant, ready to run once.

| **Action data parameters** |                                   |              |                                 |
| -------------------------- | --------------------------------- | ------------ | ------------------------------- |
| **Attribute**              | **Type**                          | **Required** | **Default / Example**           |
| `name`                     | :term[string]                     | Yes          | `Movie night`                   |
| `input_select_id`          | :term[string]                     | No           | `movie_night`                   |
| `options`                  | :term[list of strings]{to="list"} | Yes          | `["Comedy", "Horror", "Drama"]` |
| `initial`                  | :term[string]                     | No           | `Horror`                        |
| `icon`                     | :term[string]                     | No           | `mdi:movie-open`                |

The options need at least one entry, and each option can only be in it once. An initial option has to be one of the options. One that is not is refused.

Without an `input_select_id`, the entity ID follows the name, as it does in the UI, and gets a number at the end if that name is already taken. With an `input_select_id`, you get exactly that entity ID or an error: one that is already taken is refused, and does not get a number at the end.

:::

:::accordion-item{label="Example actions in YAML" icon="i-mdi-code-braces"}

A movie night dropdown, starting on horror, and its entity ID kept for the steps after it:

```yaml
action: input_select.create
data:
  name: "Movie night"
  input_select_id: movie_night
  options:
    - Comedy
    - Horror
    - Drama
  initial: Horror
response_variable: created
```

The new input select's entity ID is then in `{{ created.entity_id }}`.

### Delete an input select

Deletes one or more input select helpers.

The other half of [Create an input select](#create-an-input-select): the script that made a helper cleans it up again. It works on any input select made in the UI as well, disabled ones included.

**How to use it**

1. Open the automation or script that should do the cleaning up, and select **Add action**.
2. Search for **delete an input select**, and select **Input select: Delete an input select 👻**.
3. Under **Entity ID**, choose the input selects to delete.
4. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=input_select.delete) opens it in your Home Assistant, ready to run once. Mind that it really deletes.

### Select random option

Selects a random option of an input select.

Who cooks tonight, who takes out the bins, which scene the living room gets. Leave it to chance, and nobody can complain about the automation playing favorites. You can also limit the draw to a few of the options.

**How to use it**

1. Open the automation or script that should pick, and select **Add action**.
2. Search for **select random option**, and select **Input select: Select random option 👻**.
3. Under **Targets**, choose the input select.
4. Optionally, fill in **Options** to pick from only those. Leave it empty to pick from all of them.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=input_select.random) opens it in your Home Assistant, ready to run once.

:::accordion-item{label="Example actions in YAML" icon="i-mdi-code-braces"}

Pick who cooks tonight, from everyone in the list:

```yaml

  entity_id: input_select.who_is_cooking_tonight
```

Pick a color, but only one of these three:

```yaml
action: input_select.random
target:
  entity_id: input_select.color
data:
  options:
    - red
    - green
    - blue
```

:::
:::accordion-item{label="Known limitations" icon="i-mdi-alert-outline"}

- The options you give have to be options of the input select. When the one picked is not, the action fails with an error.

### Reverse options

Reverses the order of the options of an input select, back to front, and keeps the current option selected.

This is not a sort: the options keep the order they were in, turned around. A list that grows at the end, like a play history, then has its newest entry at the top. It does not last: a reload of input selects, or a restart of Home Assistant, puts the order back.

**How to use it**

1. Open the automation or script that should do this, and select **Add action**.
2. Search for **reverse options**, and select **Input select: Reverse options 👻**.
3. Under **Targets**, choose the input select.
4. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=input_select.reverse) opens it in your Home Assistant, ready to run once.

### Sort options

Sorts the options of an input select, and keeps the current option selected.

Home Assistant has no way to reorder the options of an input select once it is made. This at least puts them in alphabetical order. It does not last: a reload of input selects, or a restart of Home Assistant, puts the order back.

**How to use it**

1. Open the automation or script that should do this, and select **Add action**.
2. Search for **sort options**, and select **Input select: Sort options 👻**.
3. Under **Targets**, choose the input select.
4. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=input_select.sort) opens it in your Home Assistant, ready to run once.

## Use cases

What people use this for:

- Shuffle and random are fun in automations. For example, pick a random person to cook dinner or do chores, or shuffle a sequence of scenes to play.
- An input select does not let you reorder its options. Sorting at least puts them in alphabetical order.
- Let a script make the choice it needs, and clean it up again afterwards, so the helpers page only has input selects you actually use.
