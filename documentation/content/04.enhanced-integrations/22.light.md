The light :term[integration] is how :term[Home Assistant] controls anything that lights up a room.

Spook adds actions for adjusting lights, without switching them: brightness, color, color temperature and effects. `light.turn_on` does two things at once: it sets a level and it turns the light on. Adjusting a room usually means the first without the second, and there is no way to ask for that.

Then there are light groups. A light group is a light like any other. Ask one for a little more brightness, and Home Assistant averages its members, applies the step to that average, and sets every member to the result. A room with a lamp at 10% and one at 100% ends up with both at 65%. Flatter, mostly. Spook's actions work through to the members and step each from its own level.

## Actions

Spook adds six actions for lights. You find them wherever you add an action, marked with a 👻. All of them only touch lights that are already on.

### Set brightness

Sets the brightness of the lights that are already on.

"Dim the living room to half" should not light up the reading lamp somebody turned off on purpose. With `light.turn_on` on the whole room, it does. This action only touches what is lit, so you can target a whole area without thinking about what is on in it.

**How to use it**

1. Open the automation or script that should set the brightness, and select **Add action**.
2. Search for **set brightness**, and select **Light: Set brightness 👻**.
3. Under **Targets**, choose the lights, or a whole area.
4. Set **Brightness**, like `50` for half.
5. Optionally, set **Transition** to fade there over a few seconds.
6. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=light.set_brightness) opens it in your Home Assistant, ready to run once.

### Increase brightness

Turns up the lights that are already on, each from its own level.

A "brighter" button on the wall is the classic. With `light.turn_on` and a step, a group flattens every lamp to the same level, and a lamp that was off comes on. With this action, every light that is on goes up a step from where it was, and the rest stay off.

**How to use it**

1. Open the automation or script that should turn the lights up, and select **Add action**.
2. Search for **increase brightness**, and select **Light: Increase brightness 👻**.
3. Under **Targets**, choose the lights, a light group, or a whole area.
4. Set **Step**, like `10` for ten percent.
5. Optionally, set **Transition** to fade there over a few seconds.
6. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=light.increase_brightness) opens it in your Home Assistant, ready to run once.

### Set color

Sets the color of the lights that are already on.

`light.turn_on` with a color on a whole room turns the white-only lamps on, and white. This action passes over the lights that cannot do color, and the ones that are off. Target the room, and only the lights that can show the color get it.

**How to use it**

1. Open the automation or script that should set the color, and select **Add action**.
2. Search for **set color**, and select **Light: Set color 👻**.
3. Under **Targets**, choose the lights, or a whole area.
4. Pick the **Color**.
5. Optionally, set **Transition** to fade there over a few seconds.
6. Select **Save**.

### Set color temperature

Sets the color temperature of the lights that are already on, each within the range it can reach.

Warm white on one lamp is a number another one cannot manage, and a room is rarely all the same model. This action keeps every light inside its own range: ask for 2200 K, and a lamp that only goes down to 2700 K goes as warm as it can. Lights that are off, or cannot do color temperature at all, are left alone.

**How to use it**

1. Open the automation or script that should set the color temperature, and select **Add action**.
2. Search for **set color temperature**, and select **Light: Set color temperature 👻**.
3. Under **Targets**, choose the lights, or a whole area.
4. Set **Color temperature** in kelvin, like `2700` for warm white.
5. Optionally, set **Transition** to fade there over a few seconds.
6. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=light.set_color_temperature) opens it in your Home Assistant, ready to run once.

### Set effect

Sets an effect on the lights that are already on and have it.

Effect names differ per manufacturer. A room is usually a mix of lights that know this one and lights that have never heard of it. This action only hands the effect to the lights that list it, so you can target the room and let the rest be.

**How to use it**

1. Open the automation or script that should set the effect, and select **Add action**.
2. Search for **set effect**, and select **Light: Set effect 👻**.
3. Under **Targets**, choose the lights, or a whole area.
4. Fill in **Effect**, like `Colorloop`, written exactly as the light lists it.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=light.set_effect) opens it in your Home Assistant, ready to run once.

All six actions share a few rules:

::accordion
:::accordion-item{label="Known limitations" icon="i-mdi-alert-outline"}

- Lights that are off are left alone. Turning the room up should not light up whatever somebody turned off on purpose.
- Decreasing stops at the dimmest a light goes and does not switch it off. Holding a dim-down button leaves the room lit.
- A light that cannot do what is being asked is skipped, not turned on anyway: an on-or-off light has no brightness to set, a white-only light has no color, and a light without a given effect has never heard of it.
- An effect has to match the name the light lists exactly, upper and lower case included.

:::
