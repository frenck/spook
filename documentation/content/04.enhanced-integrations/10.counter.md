The counter :term[helper] in :term[Home Assistant] keeps count: it goes up or down by a step, can be reset, and can be kept between a minimum and a maximum. Handy for counting how often something happened.

Spook adds actions to create and delete these helpers from your automations and scripts.

## Actions

Spook adds two actions for counters. You find them wherever you add an action, marked with a 👻.

### Create a counter

Creates a new counter helper, the same as adding one on the helpers page.

Great for a script that needs to count something only for itself: it makes a counter, counts, and deletes it again when it is done. Or for setting up a new installation with the counters you always want, in one go.

**How to use it**

1. Open the automation or script that should create the counter, and select **Add action**.
2. Search for **create a counter**, and select **Counter: Create a counter 👻**.
3. Fill in **Name**, like `Coffee cups`.
4. Fill in whatever else you want to set: **Initial value**, **Minimum**, **Maximum**, **Step**, **Restore** or **Icon**. To pick the entity ID yourself, fill in **Counter entity ID**.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=counter.create) opens it in your Home Assistant, ready to run once.

Without a `counter_id`, the entity ID follows the name, as it does in the UI, and gets a number at the end if that name is already taken. With a `counter_id`, you get exactly that entity ID or an error: one that is already taken is refused, and does not get a number at the end.

:::

:::accordion-item{label="Example actions in YAML" icon="i-mdi-code-braces"}

Create a counter for coffee cups, and keep its entity ID for the next steps:

```yaml
action: counter.create
data:
  name: "Coffee cups"
  counter_id: coffee_cups
  maximum: 10
response_variable: created
```

The new counter's entity ID is then in `{{ created.entity_id }}`.

### Delete a counter

Deletes one or more counter helpers, disabled ones included.

The other half of [Create a counter](#create-a-counter): a script cleaning up the counter it made, or you clearing out the counters that piled up over the years. Everything in the list is checked first: if one of them cannot be deleted, none of them are.

**How to use it**

1. Open the automation or script that should delete the counter, and select **Add action**.
2. Search for **delete a counter**, and select **Counter: Delete a counter 👻**.
3. Under **Entity ID**, choose the counters to delete.
4. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=counter.delete) opens it in your Home Assistant, ready to run once. Mind you: running it deletes the counter for real.

:::accordion-item{label="Known limitations" icon="i-mdi-alert-outline"}
