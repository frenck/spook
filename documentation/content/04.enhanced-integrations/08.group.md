The group :term[helper] integration lets you combine multiple :term[entities]{to="entity"} into a single entity. Entities that are members of a group can be controlled and monitored as a whole.

Useful to control the bulbs in a light fixture as a single light in :term[Home Assistant], for example. Or to combine all the wall plugs behind your Christmas decorations into a single switch entity.

::screenshot{name="repair-group-unknown-members" alt="An repair raised by Spook for a group that has an unknown member entity."}
Spook found an issue with a group that has a non-existing entity as a member.

::

## Actions

Spook adds three actions for groups. You find them wherever you add an action, marked with a 👻. They work on groups you made in the interface, under **Settings** > **Devices & services** > **Helpers**.

### Add members to a group

Adds entities to a group, while Home Assistant is running.

Guests staying for the weekend? Put their phones in the group that says somebody is home. Moved a lamp to the hallway? Add it to the hallway lights. Changing who is in a group used to mean opening the helper settings. Now an automation can do it. Entities already in the group stay where they are, and the new ones join at the end.

**How to use it**

1. Open the automation or script that should do this, and select **Add action**.
2. Search for **add members**, and select **Group: Add members to a group 👻**.
3. Under **Group**, choose the group.
4. Under **Members**, choose the entities that should join it.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=group.add_members) opens it in your Home Assistant, ready to run once.

| :term[Action targets]                             | No targets                                                                                                                                                                                                                                                                                                                                                            |
| :term[Action response]                            | No response                                                                                                                                                                                                                                                                                                                                                           |
| :term[Spook's influence]{to="influence of spook"} | Newly added action                                                                                                                                                                                                                                                                                                                                                    |
| :term[Tools]                                      | [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=group.add_members) [![Open your Home Assistant instance and show the Actions tool with a specific action selected.](https://my.home-assistant.io/badges/developer_call_service.svg)](https://my.home-assistant.io/redirect/developer_call_service/?service=group.add_members) |

| **Action data parameters** |               |              |                       |
| -------------------------- | ------------- | ------------ | --------------------- |
| **Attribute**              | **Type**      | **Required** | **Default / Example** |
| `group`                    | :term[string] | Yes          | `light.hallway`       |
| `members`                  | :term[list]   | Yes          | `light.desk`          |

The `group` attribute names the group to add to. The `members` attribute lists the entities joining it, which have to exist and be a kind the group can hold.

If the group is set to hide its members, the ones that join it are hidden. A member that leaves stays hidden, the same as when you take one out through Settings: Home Assistant hides the members a group has, and never touches one that left. It is also the only safe answer. The registry records that an integration hid an entity, but not which one, so showing it again could undo what another helper still asks for. An entity that was already hidden, by you or by anything else, is left as it is.

Which entities a group can hold is read from the same list Home Assistant's own dialog offers, so it is not always one domain: a sensor group takes `number` and `input_number` alongside `sensor`.

A group holds either an entity ID or a registry ID, whichever the interface had when it was made. All three actions treat the two names for one entity as one member. So an entity cannot end up in a group twice, and one stored under the name you did not use still goes when you ask for it.

:::

:::accordion-item{label="Example actions in YAML" icon="i-mdi-code-braces"}

Add the desk lamp to the hallway lights:

```yaml
action: group.add_members
data:
  group: light.hallway
  members:
    - light.desk
```

:::

:::accordion-item{label="Known limitations" icon="i-mdi-alert-outline"}

- Only groups created through the interface can be changed, and the same goes for all three group actions. They cannot change a group defined in your YAML configuration, and raise an error saying so. The built-in `group.set` action does still work on that older kind of group, and it does not need a restart either.

:::
::

### Remove members from a group

Takes entities out of a group, while Home Assistant is running.

The other way round from [Add members to a group](#add-members-to-a-group): the guest goes home, the window closes, the lamp moves to another room. Naming something that is not in the group does nothing, and is not an error. So this is also how you clear out a member that no longer exists.

**How to use it**

1. Open the automation or script that should do this, and select **Add action**.
2. Search for **remove members**, and select **Group: Remove members from a group 👻**.
3. Under **Group**, choose the group.
4. Under **Members**, choose the entities that should leave it.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=group.remove_members) opens it in your Home Assistant, ready to run once.

### Set the members of a group

Replaces the members of a group with the ones you give, while Home Assistant is running.

For when you know the whole list, not just what changed: a scene that decides which lights make up "the reading corner", or an automation that rebuilds a group from scratch every evening.

**How to use it**

1. Open the automation or script that should do this, and select **Add action**.
2. Search for **set the members**, and select **Group: Set the members of a group 👻**.
3. Under **Group**, choose the group.
4. Under **Members**, choose every entity the group should hold from now on.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=group.set_members) opens it in your Home Assistant, ready to run once.

## Repairs

Spook looks through your groups for members that no longer exist, and tells you in the :term[repairs dashboard]{to="repairs"}. New to repairs? Follow [Fix your first repair](/fix-your-first-repair).

### Unknown source entity

A group has a member that no longer exists, usually because the entity was renamed or removed. The group carries on with the members it has left, so it does less than you think.

**How to fix it:** Select the repair. Spook offers to **Remove these members** from the group for you. Choose **Let me fix it myself** to change the group under **Settings** > **Devices & services** > **Helpers** instead, or **Keep them, stop telling me** if they are meant to come back. For a group set up in YAML, edit the group in your configuration. The repair disappears by itself once it is fixed.

::accordion
:::accordion-item{label="How Spook checks this" icon="i-mdi-magnify"}

Spook looks at the members of every group. When one of them no longer exists, it raises a repair that names the group and the missing member.

Before removing anything, Spook checks again. If the members the repair listed are back, or changed since Spook looked, nothing is removed, and Spook updates the repair on its own. Spook cannot edit a group set up in YAML, and says so.

:::
::
