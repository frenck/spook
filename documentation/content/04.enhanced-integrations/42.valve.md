The valve :term[integration] is how :term[Home Assistant] controls water, gas and irrigation valves.

Home Assistant can set a valve to a position, but not a bit further. Spook adds the step, the same way it does for [covers](/cover).

## Actions

Spook adds two actions for valves. You find them wherever you add an action, marked with a 👻.

Both work the same way:

- Positions are whole percentages, from 0 for fully closed to 100 for fully open, the same as Home Assistant's own.
- The step is the one you give, or ten percent. A valve does not say how far one step is, the way a thermostat does.
- A step that would go past fully open or fully closed stops there.

### Increase position

Moves a valve a step further open, stopping at fully open.

You cannot ask Home Assistant for "a bit more water". It wants a position, so you first read where the valve is, add to it, and keep it under 100. This action does that for you. Put it on a dashboard button next to the irrigation valve, and every press opens it a little further.

**How to use it**

1. Open the automation or script that should do this, and select **Add action**.
2. Search for **increase position**, and select **Valve: Increase position 👻**.
3. Under **Targets**, pick the valves.
4. Optionally, set **Step** to how many percent it should move. Ten when left empty.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=valve.increase_position) opens it in your Home Assistant, ready to run once.

### Decrease position

Moves a valve a step further closed, stopping at fully closed.

The other way round from [Increase position](#increase-position): a bit less, without working out the number, and never below fully closed.

**How to use it**

1. Open the automation or script that should do this, and select **Add action**.
2. Search for **decrease position**, and select **Valve: Decrease position 👻**.
3. Under **Targets**, pick the valves.
4. Optionally, set **Step** to how many percent it should move. Ten when left empty.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=valve.decrease_position) opens it in your Home Assistant, ready to run once.

::accordion
:::accordion-item{label="Known limitations" icon="i-mdi-alert-outline"}

- A valve that can only open and close, like most shutoff valves, cannot be targeted. There is no position to step.
- A valve that has not reported a position yet is left alone.

:::
