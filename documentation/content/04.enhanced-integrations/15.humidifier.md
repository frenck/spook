The humidifier :term[integration] is how :term[Home Assistant] controls humidifiers and dehumidifiers.

Home Assistant can set a humidifier to a target humidity, but not turn it up a step. Spook adds the step, the same way it does for [thermostats](/climate) and [water heaters](/water-heater).

## Actions

Spook adds two actions for humidifiers. You find them wherever you add an action, marked with a 👻.

### Increase humidity

Turns the target humidity of a humidifier up a step, within the limits it reports.

Setting a humidifier to a number means you have to know the number. A button on the wall that says "a bit more" does not. Without this action, that button needs a template that reads the current target, adds to it, and keeps it under the maximum. This action does all of that.

**How to use it**

1. Open the automation or script that should turn it up, and select **Add action**.
2. Search for **increase humidity**, and select **Humidifier: Increase humidity 👻**.
3. Under **Targets**, choose the humidifier.
4. Leave **Step** empty to use the humidifier's own step, or set it, like `5` for five percent.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=humidifier.increase_humidity) opens it in your Home Assistant, ready to run once.

### Decrease humidity

Turns the target humidity of a humidifier down a step, within the limits it reports.

The other way round from [Increase humidity](#increase-humidity). Handy for a "bit less" button, or for a dehumidifier in the basement that should back off a little once the rain stops.

**How to use it**

1. Open the automation or script that should turn it down, and select **Add action**.
2. Search for **decrease humidity**, and select **Humidifier: Decrease humidity 👻**.
3. Under **Targets**, choose the humidifier.
4. Leave **Step** empty to use the humidifier's own step, or set it, like `5` for five percent.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=humidifier.decrease_humidity) opens it in your Home Assistant, ready to run once.

Both actions work the same way:

- The step is the one you give, or the humidifier's own step, or one percent when it has none. That is the same as the slider in Home Assistant.
- Steps are whole percentages, since Home Assistant hands a humidifier its target as a whole number. A step of its own that is not one, like half a percent, moves a whole percent.
- The target stays within the minimum and maximum the humidifier reports. A step that would cross one stops at it.
- A humidifier that is off gets its target moved and stays off.

::accordion
:::accordion-item{label="Known limitations" icon="i-mdi-alert-outline"}

- A humidifier that has not reported a target yet is left alone.
- A target already past one of the humidifier's own limits, which some integrations report, is left where it is, and not pulled back.

:::
::
