The timer :term[helper] in :term[Home Assistant] counts down: start it, and it tells you when the time is up. Ideal for :term[automations]{to="automation"} like "turn the fan off ten minutes after the shower".

Home Assistant lets you make a timer and set how long it runs on the helpers page, by hand. Spook adds actions for it, so an automation or a script can do the same: make a timer, change its duration, and delete it again.

## Actions

Spook adds three actions for timers. You find them wherever you add an action, marked with a 👻.

### Create a timer

Creates a new timer helper, the same as adding one on the helpers page.

Great for a script that needs a timer only for itself: it can make one, and delete it again with [Delete a timer](#delete-a-timer) when it is done. No more helpers page full of timers that one forgotten script once needed.

**How to use it**

1. Open the automation or script that should make the timer, and select **Add action**.
2. Search for **create a timer**, and select **Timer: Create a timer 👻**.
3. Fill in the **Name** of the new timer.
4. Set the **Duration**, how long it runs when it is started.
5. Optionally, set the **Timer entity ID** and the **Icon**, and turn on **Restore** to keep a running timer running across a restart.
6. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=timer.create) opens it in your Home Assistant, ready to run once.

:::accordion-item{label="Example actions in YAML" icon="i-mdi-code-braces"}

A five minute timer for the greenhouse mister:

```yaml
action: timer.create
data:
  name: "Greenhouse mist"
  timer_id: greenhouse_mist
  duration: "00:05:00"
response_variable: created
```

The new timer's entity ID is then in `{{ created.entity_id }}`.

### Delete a timer

Deletes one or more timer helpers.

The other half of [Create a timer](#create-a-timer). A script that made a timer for itself cleans it up again, so the helpers page only has timers you actually use.

**How to use it**

1. Open the automation or script that should do the deleting, and select **Add action**.
2. Search for **delete a timer**, and select **Timer: Delete a timer 👻**.
3. Under **Entity ID**, pick the timers to delete.
4. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=timer.delete) opens it in your Home Assistant, ready to run once. Mind that it really deletes.

### Set duration

Changes how long a timer runs, the same as changing it in the timer's settings.

Home Assistant can start a timer for a different duration once, but the next start falls back to the one in its settings. This changes the setting itself. Like a shorter fan run in summer, set by an automation instead of by you on the helpers page.

**How to use it**

1. Open the automation or script that should do this, and select **Add action**.
2. Search for **set duration**, and select **Timer: Set duration 👻**.
3. Under **Targets**, pick the timer.
4. Set **Duration** to how long it should run, like `00:15:00` for fifteen minutes.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=timer.set_duration) opens it in your Home Assistant, ready to run once.

- Changing how a timer is set up is for admins, the same as in its settings. An automation or a script can still use it.

## Use cases

What people use this for:

- Set the duration of a timer with a single action, without going through the UI.
- Let a script make the timer it needs, and clean it up again afterwards, so the helpers page only has timers you actually use.
