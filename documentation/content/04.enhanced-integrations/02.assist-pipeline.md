An Assist pipeline is a voice assistant in :term[Home Assistant]: which conversation agent answers, which engine turns speech into text, which one speaks the reply, and which wake word it listens for. You set them up under **Settings** > **Voice assistants**.

Each of those is picked once, and nothing keeps the pipeline in step afterwards. Remove the integration behind one, and the pipeline keeps asking for it.

## Repairs

Spook looks through your voice assistants for parts that no longer exist, and tells you in the :term[repairs dashboard]{to="repairs"}. Each repair names the voice assistant and what is missing.

Fixing one always goes the same way: open the voice assistant from the repair, pick something that exists, and save. Spook looks again when you save, and takes the repair away by itself. New to repairs? Follow [Fix your first repair](/fix-your-first-repair).

### Unknown engines

A voice assistant uses a conversation agent, or a speech-to-text, text-to-speech or wake word engine, that no longer exists. Usually because the integration behind it was removed. The next voice command fails with an error about a missing provider or agent. Until then, you get no warning.

**How to fix it:** Go to **Settings** > **Voice assistants**, open the assistant the repair names, and pick an engine that exists for each one the repair lists, and save. The repair disappears by itself once it is fixed.

::accordion
:::accordion-item{label="How Spook checks this" icon="i-mdi-magnify"}

Spook checks the conversation agent, speech-to-text, text-to-speech, and wake word engine of every pipeline, and raises a repair when one of them is an entity that does not exist anymore. The built-in Home Assistant conversation agent is always there when Assist is, so it is never reported.

Only engines that are entities are checked. The same settings can also hold older provider names, like `cloud`. There is no reliable way to tell whether one of those is still around, so Spook leaves them alone.

This repair has no fix button, on purpose. Clearing the speech or voice engine would change what the assistant does without telling you, and the conversation agent cannot be left empty at all. Which engine should take over is your call, so the repair sends you to the settings of that assistant.

Spook looks again whenever a pipeline is added, changed or deleted.

:::
::

## Use cases

What people use this for:

- Trying out a cloud AI as your conversation agent, then removing it again. The pipeline you made for it keeps pointing at an agent that is not there anymore.
- Moving from one speech engine to another, like a local Whisper and Piper setup to a different one, and forgetting the pipeline still names the old engines.
