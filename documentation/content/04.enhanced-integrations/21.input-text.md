The input text :term[helper] in :term[Home Assistant] holds a piece of text that can be changed from a dashboard or from :term[automations]{to="automation"}, optionally kept to a length or a pattern, or hidden like a password.

Spook adds actions to the input text :term[integration] to create and delete these helpers from automations and scripts.

## Actions

Spook adds two actions for input texts. You find them wherever you add an action, marked with a 👻.

### Create an input text

Creates a new input text helper, the same as adding one on the helpers page.

Some text only matters for a while. The last message a script sent, the name of the guest staying this weekend, a note for whoever comes home first. Made by hand, that helper stays on the helpers page long after. Made with this action, the script makes it when it needs it, and [deletes it](#delete-an-input-text) when it is done.

**How to use it**

1. Open the automation or script that should make the helper, and select **Add action**.
2. Search for **create an input text**, and select **Input text: Create an input text 👻**.
3. Fill in **Name**, like `Last message`.
4. Optionally, set **Input text entity ID** to pick the entity ID yourself, and any of **Initial value**, **Minimum length**, **Maximum length**, **Pattern**, **Mode**, **Icon** and **Unit of measurement**.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=input_text.create) opens it in your Home Assistant, ready to run once.

| **Action data parameters** |                |              |                       |
| -------------------------- | -------------- | ------------ | --------------------- |
| **Attribute**              | **Type**       | **Required** | **Default / Example** |
| `name`                     | :term[string]  | Yes          | `Last message`        |
| `input_text_id`            | :term[string]  | No           | `last_message`        |
| `initial`                  | :term[string]  | No           | `Hello`               |
| `min`                      | :term[integer] | No           | `0`                   |
| `max`                      | :term[integer] | No           | `100`                 |
| `pattern`                  | :term[string]  | No           | `[a-z ]*`             |
| `mode`                     | :term[string]  | No           | `text`                |
| `icon`                     | :term[string]  | No           | `mdi:message-text`    |
| `unit_of_measurement`      | :term[string]  | No           | `words`               |

The minimum length cannot be above the maximum, and an initial value has to fit between them. A call that does not is refused.

Without an `input_text_id`, the entity ID follows the name, as it does in the UI, and gets a number at the end if that name is already taken. With an `input_text_id`, you get exactly that entity ID or an error: one that is already taken is refused, and does not get a number at the end.

:::

:::accordion-item{label="Example actions in YAML" icon="i-mdi-code-braces"}

Make a text helper for the last message, up to 255 characters, and keep its entity ID for the steps after it:

```yaml
action: input_text.create
data:
  name: "Last message"
  input_text_id: last_message
  max: 255
response_variable: created
```

The new input text's entity ID is then in `{{ created.entity_id }}`.

### Delete an input text

Deletes one or more input text helpers.

The other half of [Create an input text](#create-an-input-text): the script that made a helper cleans it up again. It works on any input text made in the UI as well, disabled ones included.

**How to use it**

1. Open the automation or script that should do the cleaning up, and select **Add action**.
2. Search for **delete an input text**, and select **Input text: Delete an input text 👻**.
3. Under **Entity ID**, choose the input texts to delete.
4. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=input_text.delete) opens it in your Home Assistant, ready to run once. Mind that it really deletes.

:::accordion-item{label="Example actions in YAML" icon="i-mdi-code-braces"}

Remove the last message helper again:

```yaml
action: input_text.delete

```

:::
:::accordion-item{label="Known limitations" icon="i-mdi-alert-outline"}

- Input texts set up in YAML can only be removed from the YAML. Asking for one is an error.
- Everything in the list is checked first: if one of them cannot be deleted, none of them are.

:::

## Use cases

What people use this for:

- Let a script make the text helper it needs, and clean it up again afterwards, so the helpers page only has input texts you actually use.
