Everything you set up under **Settings** in :term[Home Assistant] is yours to change by hand: turn an integration off, put a device in an area, give an entity a label, file an automation in a category. Home Assistant has no actions for most of that, so an automation or script cannot do it for you.

That is what core extensions are. Spook adds those missing actions to the core of Home Assistant: the part that keeps track of your integrations, areas, devices, entities and the like.

Some examples: a label that lands on a device when its battery runs low, and comes off when you swapped it. An integration that only runs during the holidays. A guest room that is an area of its own while somebody stays over. All of it from the automation editor, no YAML needed.

You find all these actions wherever you add an action in an automation or script. Search for what you want to do, and pick the one marked with a 👻. Every page below walks you through it step by step.
