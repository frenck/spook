Besides all the new :term[actions]{to="action"} for :term[Home Assistant] itself, Spook adds a :term[device] with :term[entities]{to="entity"} that are all about Home Assistant. It turns Home Assistant into an integration of its own: buttons to reload and restart it, and sensors that count what is in your setup.

To find them, go to **Settings** > **Devices & services**, select **Spook**, and open the device called **Home Assistant**.

::screenshot{name="device-home-assistant" alt="A new device that provides control over your Home Assistant itself."}

## Devices & entities

Spook adds one device, called **Home Assistant**, with the entities below. You use them like any other entity: on a dashboard, in an automation, or in a template.

### Buttons

Two buttons for the things you otherwise dig through menus for. Put them on an admin dashboard, and reloading or restarting is one tap away. On the device page, you find them under **Configuration**.

#### Reload Home Assistant

_Default :term[entity ID]: `button.homeassistant_reload`_

Reloads all of your YAML configuration that Home Assistant can reload without a restart, with a single press. It runs Home Assistant's own **Reload all** action. Handy right after you changed a YAML file.

#### Restart Home Assistant

_Default :term[entity ID]: `button.homeassistant_restart`_

Restarts Home Assistant with a single press. This is the normal, careful restart: Home Assistant checks your configuration first, and refuses to restart when it is broken. Need more force? That is the [Restart](/misc#restart) action.

### Sensors

Counters, lots of them. How many lights do you have? How many automations? Did that integration you just removed really take its entities with it? These sensors tell you. They keep history too, so you can watch your setup grow over time. They are diagnostic entities, so you find them under **Diagnostic** on the device page, and add the ones you care about to a dashboard yourself.

#### Total number of entities

_Default :term[entity ID]: `sensor.entities`_

The total number of entities in your system (including this one).

::accordion
:::accordion-item{label="Technical details" icon="i-mdi-cog-outline"}

This counts every entity that has a state, whether it is in the entity registry or not.

- Entities from YAML, zones and the sun are counted too.
- Disabled entities have no state, so they are not counted.
- The entities page in Home Assistant filters some entities out by default, so its count can differ.

:::
::

#### Total number of helpers per type

For each kind of :term[helper] with its own entity type, like toggles and counters, a sensor counts how many you have.

::accordion
:::accordion-item{label="Technical details" icon="i-mdi-cog-outline"}

The default :term[entity ID] is listed after each sensor below.

- Number of `counter` helpers (`sensor.counters`)
- Number of `input_boolean` helpers (`sensor.input_booleans`)
- Number of `input_button` helpers (`sensor.input_buttons`)
- Number of `input_datetime` helpers (`sensor.input_datetimes`)
- Number of `input_number` helpers (`sensor.input_numbers`)
- Number of `input_select` helpers (`sensor.input_selects`)
- Number of `input_text` helpers (`sensor.input_texts`)
- Number of `timer` helpers (`sensor.timers`)

#### Other counters

But wait, there are more counters! Areas, automations, devices, integrations and more each get a sensor too.

::accordion
:::accordion-item{label="Technical details" icon="i-mdi-cog-outline"}

The default :term[entity ID] is listed after each sensor below.

- Number of areas (`sensor.areas`)
- Number of automations (`sensor.automations`)
- Number of custom integrations installed (`sensor.custom_integrations`)
- Number of devices (`sensor.devices`)
- Number of groups (`sensor.groups`)
- Number of integrations in use (`sensor.integrations`)
- Number of persistent notifications (`sensor.persistent_notifications`)
- Number of persons (`sensor.persons`)
- Number of scenes (`sensor.scenes`)
- Number of scripts (`sensor.scripts`)
- Number of suns (`sensor.suns`)
- Number of zones (`sensor.zones`)

The number of devices counts every device in the device registry, disabled ones included. The devices page in Home Assistant filters some out by default, like disabled ones, so its count can be lower.
