## Actions

Spook extends one action of Home Assistant itself. You find it wherever you add an action, marked with a 👻.

### Restart

Restarts Home Assistant. Spook adds a **Force restart** option to the restart action Home Assistant already has.

A normal restart is careful: Home Assistant first checks your configuration, and refuses to restart when it is broken or while a database migration is running. That is what you want almost every time. When something is stuck and the careful restart never gets anywhere, forcing it stops Home Assistant right away and starts it again.

Without the force option, this is the restart you know. Spook waits for it the way Home Assistant does, so when the configuration check refuses the restart, your automation or script gets an error and does not carry on.

**How to use it**

1. Open the automation or script that should restart Home Assistant, and select **Add action**.
2. Search for **restart**, and select **Home Assistant Core Integration: Restart 👻**.
3. If you like, turn on **Safe mode** to start without custom integrations and frontend modules.
4. Only when you really need it, turn on **Force restart**. Read the warning below first.
5. Select **Save**.

Just want to see it work? [Try this action](https://my.home-assistant.io/redirect/developer_call_service/?service=homeassistant.restart) opens it in your Home Assistant, ready to run once. Careful: that run restarts Home Assistant for real.

::warning
With `force` set to `true`, Home Assistant restarts immediately and skips all safety guards. It does not check your configuration, and it even interrupts database migrations: it just kills Home Assistant to restart it as fast as possible. Not recommended. Only use it when you really have to.

:::accordion-item{label="Example actions in YAML" icon="i-mdi-code-braces"}

A normal restart, with the configuration check and everything:

```yaml
action: homeassistant.restart
data:
  force: false
```

:::
:::accordion-item{label="Known limitations" icon="i-mdi-alert-outline"}

- Restarting Home Assistant interrupts all running automations, scripts and integrations. Use it only when you need it.
