A :term[blueprint] is an automation or script someone else made, that you import and fill in for your own home. These use Spook's actions, so you need Spook for them to work.

Select **Import** to add one to your Home Assistant. **Read more** takes you to where its author explains it, and where to go with questions about it.

:blueprint-list

::note
We checked that each of these really uses Spook. We did not run all of them in a home of our own, and we did not write them: their authors did. Something off with one? Tell its author first.

::
