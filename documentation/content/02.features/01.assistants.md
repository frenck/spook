Spook hands its knowledge to AI assistants. An assistant can ask Spook which ghosts are floating around your home and what they mean. It can ask where something is used, and whether a draft automation names things that don't exist. It can also ignore a ghost or fix one for you, if you let it.

These tools are only offered on Home Assistant's own administrator API, available from Home Assistant 2026.11. They are never handed to Assist, so nobody can clean up your repairs by talking to the kitchen speaker. Every tool checks that the person asking is an administrator, and the ones that change something refuse when there is no user at all.

## Using them

There are two ways to get an assistant talking to Spook.

**In Home Assistant**, with a conversation agent like OpenAI, Anthropic or Ollama:

1. Open the settings of the conversation agent.
2. Under **Control Home Assistant**, select the **Home Assistant** API.
3. Save the settings.

**From outside Home Assistant**, with an MCP client like Claude Desktop or Claude Code: point it at Home Assistant's [MCP server](https://www.home-assistant.io/integrations/mcp_server/). Either select the **Home Assistant** API in the options of the MCP server, or use the address that serves only that API: `/api/mcp/homeassistant`. An MCP server set up to expose all APIs picks it up by itself. One set up before Home Assistant 2026.10 keeps serving only the APIs it was set up with, so it needs one of those two.

Spook's tools are not an API of their own. They are part of Home Assistant's **Home Assistant** API, next to Home Assistant's own tools for managing itself, so that is the one to look for.

The **Home Assistant** API is for administrators only, and Home Assistant refuses it to anyone else. That includes a voice assistant, which asks without a user. A conversation agent that has it selected, even next to **Assist**, stops answering those. Give your voice assistant its own conversation agent, with only **Assist**.

Then ask. "How is my house doing?", "Where is `light.kitchen` used?", or "Check this automation before I save it."

## The tools

You never call these yourself: the assistant picks the one it needs. Knowing what is there helps you ask the right question.

| Tool                      | What it does                                                                                                                                                                                                                                                                                                                        |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `spook__overview`         | A short summary: open and ignored ghosts per kind, and the oldest ones.                                                                                                                                                                                                                                                             |
| `spook__list_ghosts`      | Lists Spook's open repair issues, optionally by kind, ignored ones on request.                                                                                                                                                                                                                                                      |
| `spook__explain_ghost`    | Explains one issue: its full description, the fix options it offers right now, and what Spook worked out (like a likely rename).                                                                                                                                                                                                    |
| `spook__find_usages`      | Finds where an entity, action, label, area or floor is used: automations, scripts, scenes, dashboards, groups, helpers and template helpers. Unlike the automation and script repairs, which only look at what runs, it also reports a reference in a disabled step, because that step breaks the day somebody switches it back on. |
| `spook__check_references` | Checks a draft automation, script, scene or dashboard card for references to things that don't exist, before it is saved.                                                                                                                                                                                                           |
| `spook__list_features`    | Lists the triggers, conditions and actions Spook adds, so an assistant can use them when writing automations.                                                                                                                                                                                                                       |
| `spook__ignore_ghost`     | Ignores an issue, like selecting ignore in the repairs dashboard.                                                                                                                                                                                                                                                                   |
| `spook__unignore_ghost`   | Stops ignoring an issue.                                                                                                                                                                                                                                                                                                            |
| `spook__fix_ghost`        | Runs one of the fix options of an issue, like removing an empty area. This can delete things, so a good assistant asks first.                                                                                                                                                                                                       |

A fix that needs more than a choice from a menu is left for you to finish in the :term[repairs dashboard]{to="repairs"}.

## An agent skill, too

Agents that manage Home Assistant from the outside, through Home Assistant's MCP server or a community MCP server like HA-MCP, can also learn Spook from its agent skill. It describes every action, trigger, condition and repair Spook has, so an agent does not have to read the documentation first. In Claude Code:

```text
/plugin marketplace add frenck/spook
/plugin install spook@spook
```

The skill works with any Home Assistant version Spook supports. The tools above need 2026.11.
