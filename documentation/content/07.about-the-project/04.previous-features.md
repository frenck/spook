Some features left Spook over time. Most of the time, that is good news: Home Assistant does it itself now. This page is dedicated to those fallen features.

::card{title="Template engine extensions"}
Spook added several functions to the template engine of Home Assistant, including:

- `flatten`: Flatten lists of lists
- `md5`: Calculate MD5 hashes
- `sha1`: Calculate SHA1 hashes
- `sha256`: Calculate SHA256 hashes
- `sha512`: Calculate SHA512 hashes
- `shuffle`: Shuffle lists
- `typeof`: Reveal the type of a value

_Since Home Assistant 2025.4, these template functions are part of Home Assistant itself._

::

::card{title="Obsolete integration & platform YAML configuration repairs"}
Spook looked for YAML configuration of integrations (and older integration platforms) that can no longer be set up in YAML. If it found any, it raised a repair, to keep your YAML configuration nice and clean.

_Since Home Assistant 2023.6, Home Assistant raises repairs for these itself._

::
