Spook is a free :term[custom integration]{to="integration"} for :term[Home Assistant]. Install it once, and it does two things for you: it finds problems in your setup before you run into them, and it adds the tools you keep wishing Home Assistant had.

You don't need to write :term[YAML] (the text format Home Assistant configuration is written in) to use it. Everything Spook adds shows up in the places you already know: the repairs dashboard, the automation editor, and your list of devices.

## It finds problems for you {#what-do-i-get-from-spook}

Homes change. You rename a lamp, replace a sensor, remove an integration. The automations that used them keep pointing at things that are gone, and Home Assistant doesn't tell you. The automation quietly stops doing its job.

Spook floats through your setup and looks for exactly that. When it finds something, it tells you in the :term[repairs dashboard]{to="repairs"}: which automation, which missing lamp, and how to fix it.

::

It checks automations, scripts, dashboards, groups, helpers and more.

## It adds the tools you were missing {#cool-but-what-does-it-do}

Some features never make it into Home Assistant itself. They are too specific, too experimental, or too odd. Spook doesn't mind. A few examples of what you get:

- **New actions.** Snooze an automation for an hour and have it come back by itself. Create and remove areas, labels and helpers from an automation. Snooze every automation in a room at once.
- **New triggers and conditions.** Start an automation when a device stops responding, when a repair shows up, or on a schedule. Only continue when a person started it.
- **New entities.** Switches and sensors for parts of Home Assistant that had none, like your :term[Home Assistant Link] connection.
- **New helpers.** Flip a switch or cover the other way round, or measure how long something has been on.

Every action and helper Spook adds is marked with a 👻, so you can always tell what came from where.

## Is it safe to try?

Spook is free and open source. Finding problems changes nothing in your home. Where Spook offers to fix something for you, it asks first.

Remove Spook, and what it added is gone again. Automations that use Spook's actions, triggers or conditions stop working, so check those first. Everything else stays exactly as it was.

::note
Spook is a community project. It is not made or supported by the Home Assistant project, and it comes as-is, without warranty. If something goes wrong, the [support page](/support) tells you where to get help.

::
