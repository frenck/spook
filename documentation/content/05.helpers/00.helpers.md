Spook adds three :term[helpers]{to="helper"}. A helper takes an :term[entity] you already have, and gives you a new entity with the result: a corrected value, the opposite state, or the moment it last changed. You set them up in the Home Assistant interface, no YAML involved.

1. Go to **Settings** > **Devices & services**.
2. Select the **Helpers** tab.
3. Select **+ Create helper**.
4. Search for 👻, and select the helper you want. Every helper Spook adds carries one.

::screenshot{name="helpers-ghost-search" alt="The Create helper dialog, searched for the ghost, listing the helpers Spook adds."}
Search for 👻, and there they are.

::

Each page below walks you through the rest, field by field.

::card-group

:::card{title="Calibration" to="/calibration"}

A temperature sensor that reads a degree too high? Correct it with an offset, or a factor, and get a sensor that is right.

:::

:::card{title="Inverse" to="/inverse"}

Inverts the behavior of a switch, binary sensor, cover or valve. On becomes off, and off becomes on. The world is upside down!

:::

:::card{title="Time in state" to="/time-in-state"}

Since when has the door been closed? When did motion last go on? A moment that survives a restart, and a hiccup.

:::
