Time to get Spook 👻 settled in your Home Assistant. It takes a few minutes, and everything happens in the Home Assistant interface. No files to copy, no YAML.

Stuck somewhere along the way? The [support](/support) page tells you where to go for help.

## Requirements

Two things, before you start.

1. Read, understand, and accept [the license](/license) of Spook.
2. A working :term[Home Assistant] running version **2026.8.0 or newer**. You find your version under **Settings** > **About**.

::note
The minimum version of Home Assistant goes up over time, as Spook keeps up with Home Assistant. Nothing to worry about: it only matters that you meet it when you install Spook.

::

Got both? Then you are ready. 🎉

## Installation

Since Home Assistant 2026.11, custom integrations like Spook come from the :term[Marketplace], built right into Home Assistant. On an older version, you install Spook through :term[HACS], which is what the Marketplace grew out of.

::tabs
:::tabs-item{label="Marketplace (2026.11 and newer)" icon="i-mdi-storefront-outline"}
[![Open your Home Assistant instance and open Spook in the Marketplace.](https://my.home-assistant.io/badges/marketplace_repository.svg)](https://my.home-assistant.io/redirect/marketplace_repository/?owner=frenck&repository=spook&category=integration)

Select the button above to open Spook in the Marketplace of your Home Assistant right away. Or find it yourself:

1. In Home Assistant, go to **Settings** and select **Marketplace**.
2. The first time, the Marketplace shows a notice about installing things made by the community. Read it, check **I understand the risks and agree**, and select **Continue**.
3. Search for `Spook` and select it.
4. Select **Install**.

::screenshot{name="marketplace-search" alt="The Marketplace, searched for Spook, with Spook as the only result."}
Step 3: search for Spook. One result, no doubt about which one.

Step 4: Spook's page in the Marketplace, with the **Install** button.

No restart needed: Home Assistant takes you straight into setting up Spook, which is the next step below.

:::

:::tabs-item{label="HACS (2026.8 to 2026.10)" icon="i-mdi-package-variant"}
On Home Assistant 2026.8, 2026.9 or 2026.10, you need :term[HACS] installed. If you don't have it yet, follow [the HACS installation guide](https://hacs.xyz/docs/use/download/download/).

1. From the Home Assistant sidebar, select **HACS**. This opens the Home Assistant Community Store.
2. Select the search bar at the top, and search for `Spook`.
3. Select Spook in the search results.

   ![Screenshot showing the HACS dashboard searching for Spook.](/images/installation/hacs_experimental_find_spook.png){.mx-auto}

4. On the Spook page in HACS, select **Download** in the bottom right corner.

   ![Screenshot showing the Spook page in the HACS store.](/images/installation/hacs_experimental_download_fab.png){.mx-auto}

5. In the dialog that opens, select **Download** again.

   ![Screenshot showing the download dialog in HACS.](/images/installation/hacs_experimental_download.png){.mx-auto}

6. Once the download is done, restart Home Assistant, so it finds Spook. Go to **Settings** > **System**, select the power button in the top right corner, and select **Restart Home Assistant**.

   ![Screenshot showing the Home Assistant restart dialog.](/images/installation/experimental_restart_home_assistant.png){.mx-auto}

Once Home Assistant has restarted, set up Spook as described below.

## Activating the Spook integration

From the Marketplace, this starts by itself right after you select **Install**. After installing through HACS, start it yourself, the same way as setting up any other integration:

1. Go to **Settings** > **Devices & services**.
2. In the bottom right corner, select **+ Add integration**.
3. Search for `Spook`.
4. Select **Spook** in the search results. Not one of the helpers below it: those come later, and only if you want them.

::screenshot{name="add-integration-spook" alt="The Add integration dialog, searched for Spook, listing Spook and its three helpers: Calibration, Time in state and Inverse."}
Step 4: Spook, with its helpers below it.

::

Either way, you end up here:

1. Spook says hello, with a short word on what it does, and a fair warning that it is not part of Home Assistant. Read it, and select **Submit**.
2. Spook takes a few seconds to set itself up, and tells you it is floating around. Select **Finish**.

**🎉 Spook 👻 is now haunting your Home Assistant. 🎉**
